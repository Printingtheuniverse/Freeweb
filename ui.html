Private names

Free names ending in .__TLD__ for our group. They only work on devices set up to use this server.

1. Claim a name

Free. Ask the group owner for an invite code.

Save these now

Your key is the only way to manage . It’s shown once and saved in this browser.

2. Point your name at something

Your names will show up here.
Already claimed a name? Add it with your key

3. Set up your device

Do this once on each computer that should see the private names. You need the resolver link, which appears in your name’s box above after you add or claim a name.
  1. Firefox: Settings, Privacy & Security, DNS over HTTPS. Choose Increased Protection, then Custom, and paste the link.
  2. Chrome or Edge: Settings, Privacy and security, Security, turn on Use secure DNS, choose Custom, and paste the link.
  3. Open your name with http:// in front, like http://myname.__TLD__. Without it the browser may search instead.
Private names have no padlock (https), because no public authority issues certificates for them. They only point to the address you enter, and that server must answer for the name.
